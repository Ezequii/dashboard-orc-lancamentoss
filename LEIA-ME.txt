KIT DE ATUALIZACAO MANUAL DO JSON

1. Copie estes itens para a pasta principal do repositorio:
   - ATUALIZAR_JSON_APENAS.bat
   - pasta scripts
   - pasta atualizar_dados

2. Substitua a planilha em:
   atualizar_dados\CONTROLE_DE_REQUISICOES_2026.xlsx

3. Execute:
   ATUALIZAR_JSON_APENAS.bat

4. Confira se apareceu:
   OK_REGISTROS=...
   OK_CHECKSUM=...
   JSON ATUALIZADO COM SUCESSO

5. No GitHub Desktop, selecione somente:
   atualizar_dados/CONTROLE_DE_REQUISICOES_2026.xlsx
   public/data/orcamentos.json
   public/data/meta.json

6. Commit sugerido:
   Atualiza dados do dashboard

7. Clique em Commit to main e Push origin.

Este kit NAO usa Node.js, NAO faz push automatico e NAO altera o codigo do dashboard.
